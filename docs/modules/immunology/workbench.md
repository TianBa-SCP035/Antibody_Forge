# 项目工作台

开做前准备。路径 `/serum/workbench`，接口 `/api/serum/workbench`。页内大标题和系统标签页为「免疫工作台」；侧栏仍叫「项目工作台」。不存记录本 / 黄本蓝本 / `project_status`；方案页只读展示正式项目的初始状态「规划中」，未开展不插入 `serum_imm_project`。工作台 / Excel 共用壳见 [../workbench.md](../workbench.md)。

## 状态

`plan_status` 是工作台自己的状态字段，未开展时从预设中选择（草稿、筹备中、小鼠KO致死、已取消）。`已开展` 只能通过方案页开展写入。开展后列表展示实验表 `project_status`。`can_start`（是/否）是独立列。

操作列：未开展为「方案 / 复制 / 删除」；已开展为「详情 / 复制 / 下架」。开展在方案草稿页内完成。

页面先按「全部项目 / 计划中 / 进行中 / 已完成 / 已取消」切换状态视图，再选工作台或 Excel。计划中指尚未开展且未取消；进行中指已开展且正式项目未到终态；已完成指 `结题` 或 `无效价处死`；已取消指开展前关闭态。`can_start` 是独立筛选条件。

工作台左键点行打开右侧抽屉（无全屏遮罩，可继续点其它行；再点同一行、右键任意行或点空白关闭）；状态、优先级、可开展及鼠抗信息可在行内修改。工作台视图表头与 Excel 一样：`Shift` 拖可调业务列顺序，右键「视图」恢复当前视图默认列序（工作台还会恢复显示字段）。高级操作「显示字段」可从与 Excel 相同的全量字段里勾选，默认短列之外的先藏着。Excel 划选 / 粘贴见共用约定；本台额外：点序号/排序列选整行（切到「排序」后仍可双击改队列号）；固定选项和人员必须与前端选项完全匹配；靶点名称与编号双向同步，键入走靶点查询，双击打开靶点搜索器。

“小鼠后勤”和“抗原”分区分别提供 `mouse_remark`（小鼠备注）与 `antigen_remark`（抗原备注），均为 255 字符以内的自由文本。

`POST /list` 接受 `view_group=planned|ongoing|completed|cancelled`，并返回互斥统计 `all / planned / ongoing / completed / cancelled` 与独立的 `can_start`。统计忽略当前状态视图和可开展筛选，但保留关键字检索。

综合搜索覆盖靶点名称 / 编号、项目名称 / 编号 / 项目集编号、实验号、PM 和开展人；命中多类字段时按上述字段顺序确定相关性，再按工作台队列顺序排列。常驻筛选依次为课题类型、免疫方式、归类鼠型、小鼠运输、抗原到货、审核结果和开展条件；齿轮高级区放 PM、优先级、开展人、审核人、状态、种属交叉、小鼠品系、纯合/杂合、提供地区、代下扩繁、抗原来源、LNP 下单、冲击细胞和方案内容。除状态视图与开展条件外，其余筛选会同步约束上方状态统计。
高级操作区在工作台视图提供「显示字段」；列表导出沿用当前全部筛选并导出所有匹配的工作台主表字段，不包含方案草稿子表。

## 优先级

与效价实验列表相同：`吉吉国王` > `非常紧急` > `加急` > `正常`，带颜色；接口只接受这四个值。

## 实验号

工作台、实验主表均有 `experiment_id` 唯一键。草稿号 `SCP-YYYYMMDD-HHMMSS-XXXX`（4 位随机），仅首次写入生成；撞键则换号重试。

开展：已填写项目编号和负责人，且当前用户具备免疫项目编辑权限（`serum.project.edit` 或 `serum.project.edit_all`，此时不校验负责人）。负责人不是当前用户且没有全量编辑权限时，页面提示开展后将无法编辑，但允许继续；开展成功后按正式项目的页面与负责人权限进入编辑页、详情页或返回工作台。发正式号 `{project_code}{序号}`，插入 `serum_imm_project`（对齐字段，`project_status=规划中`），已有方案子表一并改为正式实验号，工作台行保留。入口在方案草稿页，不在列表。

下架（同一事务，开展的逆操作）：仅 `规划中` 且无效应工单 / FACS / ELISA 板时可下架。对齐字段写回工作台，子表改回新的临时号，删除 `serum_imm_project`，工作台回到 `草稿`。正式号空出后再次开展可复用。

复制：新建草稿行与新的临时号。只带方案骨架（靶点、品系、免疫方式、抗原、步骤、titer 标靶/PC 等）。不复制项目编号、项目集编号、小鼠方案号、实验号、开始日期、开展人，以及小鼠后勤 / 审核 / 开展现场状态；小鼠号、笼位、步骤实际日期清空。原记录不动。

## 排序与优先级

列表默认按 `id` 倒序（越新越靠前），与免疫实验列表、效价页相同。表头为「序号」，格子里是本页行号。点该表头改为「排序」，按队列值排并显示 `sort_order`；再点恢复默认。Excel 该列表头同样切换，不再左键全选该列。

`sort_order` 只给未完成的行：稠密 1..N，档位约束能插在哪一段。终态出队，值为 `NULL`，界面显示 `-`，不能改号、不能拖。终态：`结题`、`无效价处死`、`已取消`、`小鼠KO致死`。改回进行中则插回本档队尾。打开列表时若终态仍占着号，会清掉并重编号剩下的队列。

拖行改序只在「排序」模式下可用，且只提交进行中的行；终态行仍显示在全部列表末尾，但不参与改序。改排序号 / 改优先级 / 拖动 / 删除后，只把未完成行重写成 1..N。新建 / 复制默认「正常」并落到未完成队尾。

改 `sort_order` 或拖动：**不改优先级**。先在未完成队列里找到本档可插入的下标（更高档之后到本档最后一行之后），目标落在本档内则插入该处；落到更高档则插到本档队首；落到更低档则插到本档队尾。然后重编号。

只改优先级：**会改序号并挤开后面的未完成行**。降档插到目标档队首；升档插到目标档队尾。

## 种属交叉

工作台 `species_cross` 存英文逗号拼接串，例如 `人,猴,鼠`，界面显示为 `人，猴，鼠`。选项固定为「人 / 猴 / 鼠 / 狗 / 猫 / 空白」，各项可以自由多选；接口拒绝选项外的值。方案页抗原种属仍是另一套字段。

## 免疫方式

工作台 `immuno_method` 与种属交叉相同：存英文逗号拼接串，例如 `蛋白,DNA`，界面显示为 `蛋白，DNA`。选项固定为「蛋白 / DNA / LNP / 细胞 / 混合」，不允许自定义输入；工作台抽屉和 Excel 都是多选，Excel 键入或粘贴必须与上述选项完全匹配（中英文逗号均可）。接口拒绝选项外的值。筛选按单个选项命中包含该方式的记录。

## 归类鼠型 / 小鼠品系

开展前，工作台行上的 `mouse_strain` / `mouse_strain_category` 是 PM 使用的粗粒度规划字段，直接从工作台表读取和筛选，不反查小鼠分组。首次进入空方案时，如果这两个字段有值，会用它们在页面中初始化第一个小鼠分组；初始化本身不触发保存，用户编辑、主动保存或开展时才随整份方案写入。此后方案分组与工作台规划字段互不回写。

开展时，正式项目的鼠型字段从方案中的全部小鼠分组去重并以 `+` 拼接生成。开展后列表按正式项目字段展示，工作台抽屉中的这两个字段只读。

## 子表与删除

草稿挂现有小鼠 / 抗原 / 步骤 / titer 子表。方案页 `/serum/workbench/scheme?id=`（工作台主键），`POST /save_scheme`，不插主表。已开展记录按权限进入正式编辑页或只读详情页；两者都无权限时仍可在工作台方案页只读查看。

高级筛选「方案内容」不区分工作台状态，只判断小鼠组、抗原、步骤、效价靶点、PC 五类子表是否至少有一条记录。计划中记录的子表是草稿方案，已开展记录的子表是正式方案数据；「有内容」不代表方案完整或审核通过。首次进入空方案时页面自动生成的 G1 不立即计入，只有用户编辑、主动保存或开展并写入子表后才计为有内容。

方案保存是完整文档替换：`mouse_groups` / `antigens` / `steps` / `titer_targets` / `titer_pcs` 五类集合必须全部出现，只有显式 `[]` 才表示删除。子记录 ID 必须属于当前临时实验号；步骤引用的组别和抗原必须存在于同一份方案。

详情返回 `scheme_revision` 内容指纹，指纹只覆盖方案页实际编辑的头字段和五类子表；工作台排序、优先级、审核及后勤字段不会让方案保存产生无关冲突。其他用户先修改过同一方案时返回 409，不允许后到的整份自动保存静默覆盖；页面提示后重载最新数据。写入先校验子记录归属，flush 后在所有权行锁内计算下一版 revision，再提交事务。页面按 revision 串行自动保存，离开或 A→B 前 flush；缓存组件不监听全局 `$route.query.id`。

正式免疫编辑页采用同样的 3 秒防抖、串行补存、离开前 flush 和 `project_revision` 冲突校验；项目编号变更后的实验 ID 由后端统一生成并回传。`project_revision` 只覆盖正式编辑页会写回的项目字段和五类方案子表，不包含由列表或细胞模块独立维护的实验记录本号、制备状态。鼠号、笼位、效价靶点和阳参等会改变 revision 范围内数据的独立写接口，共用正式项目或工作台所有权行锁。

未开展且未关联正式项目的记录可删，并清理同实验 ID 的方案子表。工作台「下架」仅 `规划中` 且无效应数据时可撤回。`已取消` / `小鼠KO致死` 不能开展。
免疫编辑页移除：已有效价工单 / FACS / ELISA 板时禁止操作；无效应数据且有对应工作台行时撤回为草稿（不要求仍为「规划中」），没有工作台行时永久删除正式项目及相关数据。

## 接口

查看页面和只读接口统一使用 `serum.page.workbench`。`serum.workbench.edit` 为管理员全部编辑；`serum.workbench.draft_edit` 可新建、复制、维护和删除草稿，但不能改状态、审核结果、是否可开展、审核人，也不能开展或下架；`serum.workbench.support_edit` 不限制记录状态，但只允许编辑“小鼠后勤”和“抗原”字段。多项权限同时具备时取并集。开展只允许全部编辑权限，并另需 `serum.project.edit` 或 `serum.project.edit_all`。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/list` | 分页；可传 `view_group`，返回状态视图 `stats` |
| POST | `/export_list` | 按当前筛选导出全部工作台主表数据，不含方案子表 |
| GET | `/options` | 工作台自有筛选 / 编辑选项 |
| GET | `/detail` | 含子表 |
| POST | `/save` | 无 id 新增；有 id 时只更新传入字段，不存在返回 404 |
| POST | `/save_batch` | 表格脏行单事务保存；任一行失败则全部回滚 |
| POST | `/save_scheme` | 必填工作台 `id`、完整草稿头、五类子表及 `scheme_revision` |
| POST | `/delete` | 见删除规则 |
| POST | `/start` | 发正式号并开展；另需免疫项目编辑权限 |
| POST | `/unlist` | 下架撤回实验 |
| POST | `/copy` | 复制为新草稿 |
| POST | `/reorder` | `moved_id` 放到 `target_id` 当前队列位，再重编号未完成行；需全部编辑权限；终态不参与 |
