08 · STRUCTURE SEARCH

蛋白结构检索

使用 PDB ID 或 UniProt accession 查询实验结构与预测模型的关键信息。

输入四位 PDB ID，例如 4HHB、1HZH 或 7KMG。

STRUCTURE KNOWLEDGE 输入标识符后查询

查看实验方法、分辨率、发布日期和模型置信度等信息。

PDB 模式呈现实验结构摘要；AlphaFold 模式展示对应 accession 的预测模型与置信度。
