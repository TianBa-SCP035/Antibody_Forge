# 权限和系统管理规划

当前阶段先不建设新的权限表，也不拆分新数据库。开发环境使用 `DEV_USER_OPENID` 模拟真实用户，权限表现先沿用 Serum 页面内的角色和负责人判断。

后续系统稳定后，再建设统一的“系统管理”模块：

- 用户管理：本地账号、云之家绑定、禁用、重置密码、分配角色、登录记录。
- 角色管理：角色增删改查、角色绑定页面和按钮权限。
- 权限管理：维护页面权限、按钮权限、接口权限的权限点。
- 操作日志：记录关键写操作、操作者、对象、时间、结果和错误信息。

长期权限模型采用“角色权限为主，用户单独覆盖为辅”：

```text
用户 -> 用户角色 -> 角色权限
用户 -> 用户权限覆盖 -> allow / deny
最终权限 = 角色权限 + 用户 allow - 用户 deny
```

正式登录方案为本地账号密码和云之家自动登录并存。无论哪种登录方式，最终都映射到系统用户和统一权限集合。
