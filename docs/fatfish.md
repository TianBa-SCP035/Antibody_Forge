# FatFish 桌宠

Antibody Vita 里的鲸鱼娘桌宠「大肥鱼」：闲聊、读当前页、代填表单建议、导出 / 自定义汇总，以及跟着用户打开过的列表页学接口取数。

## 目录

| 路径 | 内容 |
|------|------|
| `bbctg_vita_web/apps/antibody_vita/src/components/fatfish/` | 前端模块（18 个源文件） |
| `bbctg_vita_web/apps/antibody_vita/public/fatfish/` | 动画 webm、头像、光标；署名见目录内 `ATTRIBUTION.txt` |
| `pet-proxy/` | 本机代理（标准库 Python，无第三方依赖） |

`app.vue` 挂载 `<FatFishPet />`（登录页和业务页共用）。`vite.config.ts` / Nginx 把 `/api/pet` 转到本机代理（本地与 prod `18765`，test `18766`），**必须写在通用 `/api` 之前**。

## 启动

`start_dev.bat` / `start_dev.sh` 随后端一起启动（Linux 另有 crontab 看门狗）。单独调试：

```bash
cd pet-proxy
python server.py        # 端口用 PET_PORT 覆盖，缺省 18765
```

健康检查：`GET http://127.0.0.1:18765/api/pet/health`。

模型地址可用环境变量覆盖（缺省为内网 OpenAI 兼容地址）：

- `PET_QWEN_BASE` / `PET_QWEN_MODEL`
- `PET_DEEPSEEK_BASE` / `PET_DEEPSEEK_MODEL`

## 代理接口

| 路径 | 用途 |
|------|------|
| `POST /api/pet/agent` | 数据任务：DeepSeek 选工具；浏览器用当前登录态执行 |
| `POST /api/pet/chat` | 闲聊 / 页面点评（Qwen） |
| `POST /api/pet/compress` | 长期记忆压缩（Qwen） |
| `POST /api/pet/lines` | 即时反应台词（Qwen） |
| `POST /api/pet/labels` | 给页面上没有表头可对照的接口字段起中文表头（DeepSeek，每个数据源一次） |

代理只听 `127.0.0.1`、不发 CORS、只收 JSON（≤ 512 KB）。生产部署时 `/api/pet` 应放在已登录的同源反代后面，不要把无鉴权进程直接暴露到公网。

## 依赖边界

- 只有 `petTools.ts` 引用业务接口（`#/api/serum`、导出、效价结论）。
- 只有 `session.ts` 读宿主登录态和路由（`@vben/stores`、`vue-router`）。
- `reportBuilder.ts` 按需加载宿主已装的 `xlsx`。
- 其余文件只依赖 Vue、DOM 和 `/api/pet/*`。

新业务页一般不用适配：打开过一次列表即可统计 / 联查；Element Plus 带保存类按钮的表单可代填建议。专门业务计算需成对加 `petTools.ts` 执行器与 `pet-proxy/agent_tools.py` 定义。

## 能力摘要

- **两条路径**：闲聊走 Qwen 人设；带业务词 / 实验 ID / 菜单模块名 / 帮填表走 agent（DeepSeek 无人设 + Qwen 一句开场白）。模块名也认简称（菜单名去掉「库 / 列表 / 管理 / 工作台」等后缀、按「与 / 及」拆开），但简称要和「多少 / 哪些 / 查一下」这类查询词同时出现才算。
- **查询与报表**：`query_data` 只在对话里回答（精确计数 + 最多 20 行明细，不出文件），用于列清单、查某条记录、填表找参考；`build_report` 用于统计汇总和要 Excel。两者参数相同，任一已认识的数据源都能多条件筛选、分组、联查。
- **表头**：先用页面表格逐行比值学到的中文表头（含状态码翻译）；页面不是表格、或该字段页面上没显示时，第一次取数会把字段名和几个样例值发给模型起中文表头，按数据源缓存，起不出的保留原名。原字段名仍可作为列名使用。
- **Excel 样式**：`xlsxWriter.ts` 自己写 xlsx（SheetJS 社区版写不出样式，打包用它自带的 CFB），不加依赖。深蓝表头、隔行浅底、细边框、冻结表头（8 列以上连首列）、自动筛选、合计行加粗；整数千分位、小数两位、「占比(%)」列写成百分比；取值不多的短文本列（最多两列）按值上色。只按数据形态决定，不按模块。
- **卡片确认**：填表点「应用」、固定导出点「确认导出」、报表点「下载 Excel」、未认识页面点「打开页面」。用户明确要文件且条数够少时，导出可跳过第二张确认卡。带按钮的卡片等用户处理；纯回答卡片按字数停留 12–60 秒后自动收起（鼠标停在上面或输入框开着时不收），内容留在对话历史里。
- **代填控件**：输入框、下拉（含多选，选项名里带逗号也能对上）、远程搜索下拉（靶点、人员：应用时先跑页面自己的搜索再选）、日期、数字、开关、单选、复选框组。时间选择器、点开弹窗编辑的格子、上传需要手动。依赖前面内容才出现的表格（如按分组生成的页签）要分两次应用。以上都按 Element Plus 控件的行为识别，不按页面适配。
- **筛选口径**：`keyword` / `owner` / `status` / `mine` 只对内置 `projects` 生效，代理拒绝把它们传给其他数据源（以前会被静默忽略、返回全量）；其他数据源按列筛选用 `where`。
- **跟着页面取数**：同源、像列表、路径无写类词；POST 还要有读类词。重放前再查一遍。菜单里还没打开的页面可出卡请用户打开，加载后自动认识并接着回答。
- **表头与码值**：接口字段和页面表格逐行比值，对上的用页面表头命名；状态这类页面翻译显示的字段（一一对应且取值重复）同时学码值，导出时 `1` 写成「进行中」。页面上没出现过的码值、页面上没有的字段保留接口原样。
- **养成**：`useCare.ts` 的饱腹 / 精力按真实时间变化（页面开着每分钟推进，关掉按睡觉补算，最多 16 小时），心情向「35 + 饱腹和精力均值 × 0.35」回归，所以单靠时间不会掉到「蔫」；「开心」靠喂、摸、玩和完成任务。数值按 30 个工作日模拟定过：每天喂一次不会饿，完全不喂才会一直饿。只影响语气和动作，不影响干活质量。
- **台词**：`lines.ts` 是固定台词兜底；`/api/pet/lines` 按当前心情和天气为 13 类场景（戳、摸、喂、闲置、开机问候、午饭、下班、深夜、保存成功等）各写几句，和固定台词混着用，按账号存在浏览器。提到天气时段的类别 2 小时过期、其余 24 小时；不该带天气的类别由代理过滤。
- **记忆**：按账号存摘要与近史；压缩不记查到的数字；摘要硬上限 800 字。

## 安全边界

- 没有改 / 删 / 提交工具；填表只写到页面控件，由用户点卡片；自动保存页会由页面自己持久化（卡片提前标明）。
- 模型空口说“点卡片下载 / 已生成 Excel”但本轮没调用卡片工具时，代理先纠偏一次；仍不调用则改成如实说明没生成，不把假下载话术交给用户。闲聊模型自称“没法导出”也会改走 agent。
- 密码框与敏感字段名不送模型；正文打码邮箱和大陆手机号；焦点字段同样打码。
- `pet-proxy/logs/agent_trace.jsonl` 含业务内容，已在 `.gitignore`；超过约 5 MB 轮转。

素材署名与许可证见 `public/fatfish/ATTRIBUTION.txt`。
