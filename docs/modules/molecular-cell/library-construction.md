# 分子与细胞 · 文库构建

路径 `/molecular-cell/library-construction`，质控详情 `/molecular-cell/library-construction/result?id=`，接口前缀 `/api/molecular-cell/library-orders`。

本模块接收上游筛选、细胞制备、外周血或噬菌体筛选产生的材料，记录建库排程、工艺关键数据、材料/产物位置与建库内部质控。胶图和 ABI/AB1、CLC、FASTA 等引物核对文件统一视为“引物质检文件”；正式一代测序、NGS 申请、上机、run/lane、FASTQ 和分析结果属于其他测序模块。

本次是无正式业务数据前的不兼容重建。已有开发库若创建过旧版文库表，应先按“关联表 → 物理文件表 → 字典表 → 工单表”的顺序删除四张旧表，再执行 `docs/vita-database.sql` 中对应建表与权限段；不能只依赖 `CREATE TABLE IF NOT EXISTS` 覆盖旧结构。

## 业务分类

`build_type` 只表示实际工艺：

- `plate_single_cell`：单细胞孔板
- `pooled_bcr`：混管 BCR
- `phage_display`：噬菌体展示
- `phage_ngs`：噬菌体 NGS
- `peripheral_blood_bcr`：外周血 BCR

以下维度单独记录，不能再混入类型：

- `sample_source`：合并后的样品来源，如 Beacon、达普打板、达普打管、细胞/核酸、噬菌体产物或眼眶血。
- `mouse_model`：上游归类鼠型。
- `sample_type`：保存归类鼠型时，RL、RL-KO 带出 Lite，RN、RN-KO 带出 Nano，多个鼠型只看第一个。改样品类型不改鼠型。对不上的鼠型不改已有样品类型。交接和手工编辑同一条规则。
- `index_mode`：前端显示“Barcode 方式”，可选不加、i7、i5、双端 i7 + i5；这里的“双端”不等于双端测序。

Barcode（i7 / i5 Index）在单细胞孔板、噬菌体展示、噬菌体 NGS 和外周血 BCR 中按实际方案记录。混管 BCR 不显示该区，其 H/K/L 正反向引物直接从同一字典选择。

一张工单对应一个主要上游来源和一个主要产物。多板只保存 `plate_nos` 板号列表，阳性细胞数保存整批总数，不记录每板数量。前端使用一个输入区填写板号，回车、中英文逗号、制表符和粘贴的换行都按分隔符解析。多个附件由文件关联表记录。建库编号是实验员业务标识，允许重复；系统工单号唯一。

## 表

### `molecular_library_order`

字段按以下层级组织：

- 来源项目快照：`source_project_code`（前端显示“项目编号”）、`study_type`（课题类型）、靶点、PM、归类鼠型和样品类型；不保存来源实验号。
- 工艺分类：`build_type`、`sample_source`；噬菌体工单额外记录实验类型（抗体发现/亲和力改造）和实验目标。
- 来源材料：样品交接日期、上机日期、采血日期、阳性细胞数、板号、细胞类型和免疫阶段。发现台剖鼠日期交接后作为上机日期；阳性细胞数保留“约120”“>100”等实验员原始写法。
- 排程：状态、优先级、负责人、开始时间、完成时间，并以只读输入框展示来源发现 ID；有来源时可点击跳转到对应发现工单，不另设计划开始/完成。
- 工艺记录：五类建库都记录实验记录本号；单细胞孔板另有 PCR 起止、执行/检测人员及转染时间与人员，噬菌体 NGS 另有建库批号。
- 材料与产物：RNA、cDNA、文库位置，cDNA 浓度，初始/有效库容原始文本，以及按 bp 保存但标题不带单位的片段大小。
- 引物与 Barcode：混管 BCR 保存 H/K/L 各自的正向引物、反向引物和浓度；其余四类可记录 i7/i5 名称、序列与字典引用。不再保存浓度单位。
- 质控：只保存总体质检结论、质检人、日期和说明，不另设测序分析人、测序结论或测序说明。

实验日期都使用 `DATE`，只记年月日，包括交接、上机、采血、质检、工单开始/完成、PCR 起止和转染。创建时间 `created_at` 由数据库自动写入，不在表单里编辑。片段大小使用整数，浓度使用数值；阳性细胞数和初始/有效库容按实验员原始文本保存，不错误解释为固定数值、滴度或 CFU。

类型只可在 `待处理` 修改。状态允许：

- 待处理 → 建库中 / 已取消
- 建库中 → 待处理 / 待质检 / 已取消
- 待质检 → 建库中 / 已完成 / 质检不通过 / 已取消
- 质检不通过 → 建库中 / 待质检 / 已取消
- 已取消 → 待处理
- 已完成保持终态

类型变化会清除其他 profile 专属字段；来源项目快照、排程、公共质控不清除。

### `molecular_primer_index_catalog`

承接 `八口命名.xlsx`：

- 旧 8 nt 名称/序列和 UDP 10 nt F/R 名称/序列分别记录 `family`。
- 保存名称、原始方向、版本、短序列和同源臂；完整序列需要时由“同源臂1 + 短序列 + 同源臂2”计算，不重复落库。
- 名称唯一；短序列允许重复。
- 在实验规则确认前，不自动把 F/R 映射为 i7/i5，也不自动反向互补。

建表后可从服务端目录导入实验员工作簿：

```powershell
python -m modules.molecular_cell.library_orders.catalog_import "C:\path\八口命名.xlsx"
```

导入按名称更新，可重复执行；保留工作簿中的 F/R、版本、短序列和同源臂原值，不生成 i7/i5 映射。

### `molecular_library_result_file`

仅保存物理文件属性：哈希、路径、MIME、大小和首次保存时间。上传先写临时文件并完成 DRM 处理，再按实际落盘内容计算大小和 `sha256`；哈希唯一，相同内容只落盘一次。

### `molecular_library_result_link`

保存文件在具体工单中的业务信息：当前显示文件名、是否为最终质检文件、该工单在胶图中的归一化矩形区域列表、上传人和上传时间。每个区域包含坐标和可自定义的标记名称。文件用途不落库，根据当前文件扩展名实时推导为 PCR 检测报告、胶图、引物质检文件或其他，避免名称与类型形成两套状态。最终标记与框选区域均属于关联关系，同一物理胶图可在不同工单中保存不同标记，同一工单也可框选多个不连续区域。

`order_id` 和 `file_id` 使用数据库外键约束。下载/删除使用关联 ID。删除只解除当前工单关联；仅当物理文件已无任何引用时才提交删除物理记录，再清理磁盘文件，避免事务回滚后留下失效引用。

## 发现交接

发现交接只复制必要来源快照，不复制发现台负责人和小鼠品系。弹窗选择 `build_type`，再明确 `sample_source`：

- Beacon 可预选单细胞孔板工单。
- 同时有 Beacon 与达普可预选 Beacon+达普打板。
- “达普”不猜孔板还是混管，由用户选择。
- “噬菌体”预选噬菌体展示。
- 不因发现台出现 NGS 字样直接猜测具体 NGS 建库 profile。

孔板、混管和展示前噬菌体工单从发现交接时要求先有剖鼠日期，并将其写入文库工单的上机日期。交接后早期发现安排推进到 `待建库`；包含展示前噬菌体建库时推进到 `待噬菌体`。不因建库完成自动推进到 `待测序`。

发现安排一旦产生建库工单即保留来源追溯关系，即使工单已取消也不能直接删除发现安排；如确认两边记录都不再需要，应先删除建库工单。

## API

- `GET /meta`：建库类型、样品来源、样品类型、Barcode、混管细胞类型、状态和质控元数据。
- `GET /catalog/options`：搜索启用的引物/Index 字典。
- `POST /list`、`POST /export_list`：分页、统计和导出。
- `GET /by-discovery`、`POST /handoff`：交接预览与创建。
- `POST /save`、`POST /delete`：工单写入与删除；取消统一通过 `/save` 更新状态，删除工单时只清理已无其他工单引用的质检文件。
- `POST /files/list`、`POST /files/upload`、`POST /files/update`、`POST /files/delete`、`GET /files/download`：质控文件及工单级最终标记/胶图区域。

## 页面

工作台默认显示项目编号、靶点名称、建库类型、样品来源、样品类型、建库编号、负责人、状态、优先级和操作。归类鼠型、课题类型、PM、来源发现 ID、实验记录本号、交接/上机/开始/完成时间及质检信息可通过“显示字段”按需开启。

常用筛选依次为关键词、状态、优先级、负责人、样品来源、靶点和上机日期。高级筛选保留样品类型、归类鼠型、课题类型、PM、细胞类型、来源发现 ID、实验记录本号、备注及工单起止日期。右键“查询”清空全部筛选；发现工作台和免疫工作台本身没有独立重置按钮，其他列表页的重置按钮保持原样。

Excel 视图包含系统工单号、来源发现 ID 和全部面向用户的业务字段，不包含数据库主键、目录外键、文件哈希及审计时间等技术字段。未选择建库类型时显示完整字段集，但每行不适用于自身建库类型的实验字段只读；明确选择某一统计块或建库类型后，仅保留公共字段及该类型适用的实验字段。切换类型不会覆盖用户保存的全局列顺序。

质控详情页保留三栏审阅台：

- 左侧固定上传块与文件轨，文件用途按扩展名实时识别，支持关联级改名，最终质检文件置顶；
- 中间胶图查看器支持亮度、对比度、反相、增强、缩放、拖拽、填充窗口和复位；可用按钮后左键框选，也可按住 Shift 后左键拖动直接添加区域；新增区域后按 Enter 可打开轻量命名卡片，点击标签也可改名；填充、反相和增强状态在切换文件时保留；
- 右侧合并为质检判读、样品信息和建库记录三个视图并自动保存；状态和优先级只在页头编辑，建库记录不重复显示。

业务字段布局集中在 `libraryColumns.js`；后端对枚举和字段适用范围做最终校验，`/meta` 为列表筛选提供状态、优先级和样品选项。
