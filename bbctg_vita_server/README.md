# bbctg_vita_server

FastAPI 后端，入口 `server.py`。

日常请用仓库根的 `start_dev.bat` / `start_dev.sh` 启停。单独调试后端时，在本目录执行 `python server.py`；运行前需准备环境配置和数据库，完整步骤见 [部署文档](../docs/deploy.md)。

测试目录、命名和执行命令见 [后端结构「测试」](../docs/backend-structure.md#测试)；代码检查执行 `ruff check .`。
