# 抗体发现 · NGS测序

> 文库构建的下游、合成与验证的上游。一行是一次测序上机：同一建库编号可以上机多次。相关：[文库构建](../molecular-cell/library-construction.md) · [合成与验证](./synthesis-progress.md) · [项目工作台共用约定](../workbench.md)

## 1. 入口与权限

- **前端路由**：`/discovery/ngs`（`src/views/Discovery/ngs/NgsList.vue`）。
- **菜单**：`menu.discovery`、`menu.discovery.ngs`，排在合成与验证下面。
- **接口前缀**：`/api/discovery/ngs`。

| 权限码 | 作用 |
|---|---|
| `discovery.page.ngs` | 打开页面，列表、选项、表头取值、导出 |
| `discovery.ngs.edit` | 新建、保存、批量保存、删除、从文库交接、送合成 |
| `molecular.library.edit` | 只在文库构建页上把测序类工单交接过来，不授予 NGS 页面编辑 |

## 2. 数据

主表 `discovery_ngs_run`。测序单号 `NGS-yyMMdd-XXXXXX`，创建时生成。

样品库：`Nano`、`Lite`、`噬菌体`、`研发库`、`外来带样`。项目级别：`公司内部研发`、`客户关注`、`客户付钱`、`PCC过会`、`数据包`、`公司重点`，可空。

状态：`待上机`、`已上机`、`已送合成`、`已完成`、`已取消`。没指定状态时，填了测序上机日期从 `待上机` 变为 `已上机`，清空日期且当前是 `已上机` 则回到 `待上机`。`已送合成` 只由送合成写入。`已完成`、`已取消` 可手改，送合成之后也只能改成这两项。

噬菌体多出来的样品来源、筛选目标、片段大小、barcode、是否已测序，和其他样品库用同一行，不用时留空。

## 3. 交接

文库构建的「交接」：单细胞孔板仍去转染与表达。混管 H/K/L、混管 Barcode、外周血 BCR、浆细胞 NGS、噬菌体展示、噬菌体 NGS 新建一条测序单，带上建库编号、项目、靶点、PM、小鼠品系、细胞数量、建库上机日期；噬菌体再带筛选目标。已取消的不能交接。同一文库可以交接多次。配了建库类型权限的人只能交接自己范围内的工单。

送合成：测序单已填送合成转码、靶点、小鼠品系、PM，且未取消、尚未送出。新建一条合成与验证工单，订单性质 `常规合成`、供应方式 `合成到货`，转码、靶点、小鼠品系、PM、项目、批次号带过去。测序单记下合成单号，状态改为 `已送合成`。之后不能再改样品库、转码、靶点、小鼠品系、PM、项目编号、课题类型，也不能删除。
