04 · LIABILITY SCAN

抗体序列风险位点扫描

快速标记常见序列基序与敏感残基，帮助决定后续需要重点复核的位置。

风险基序不等同于实际修饰；结果必须结合结构、暴露度、制剂与实验数据判断。

05 · UNIPROT LIVE

UniProt 公共条目查询

通过官方 REST API 读取公开蛋白知识；仅发送 accession，不发送你的序列。

数据来源：UniProt REST API。请避免自动化批量请求。

LIVE KNOWLEDGE 输入 accession 后查询

例如 P04637（人 TP53）或 P21802（人 FGFR2）。

公共数据可能随 UniProt release 更新。关键注释请回到 UniProt 官方条目 ↗ 核对并按官方要求引用。

下列任务依赖数据库、HMM、结构模型或大规模计算。当前版本采用官方入口跳转， 避免未经许可抓取网页，也避免在没有明确同意时上传未公开序列。
